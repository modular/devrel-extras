# Session 1: Language Fundamentals

July 9, 2026 · 60 minutes

---

## What we'll cover

1. **Setting up a Mojo project** — install Mojo with pixi and run your first program
2. **Why Mojo** — strict typing, memory safety, and compiled vs. interpreted
3. **Functions, operators, and control flow** — solving Project Euler problems live
4. **Structs** — grouping data with the code that operates on it
5. **Q&A** — 15 minutes open to questions

---

## Objectives

By the end of this session you should be able to:

- Create a Mojo project with `pixi` and run a program with `mojo` and `mojo build`
- Declare variables with `var`, annotate types, and understand static typing
- Define functions with `def`, and type their arguments and return values
- Use keyword arguments, optional arguments with defaults, and variadic arguments
- Control flow with `for`, `while`, `if`/`elif`/`else`, `break`, and `continue`
- Propagate errors with `raises` and handle them with `try`/`except`
- Define a struct with typed fields, an `__init__` constructor, and methods
